- **SA vs NSA is critical.** Kalshi settles on seasonally adjusted headline number. Always verify settlement metric before generating picks. Read `rules_primary` field on the market.
- **Cross-reference FRED** (SA data) before quoting any economic number. Don't rely on a single source.

- **Kalshi API field names:** Use `_dollars` suffix (yes_ask_dollars, not yes_ask). close_time not close_ts. volume_fp not volume.
- **Kalshi auth:** RSA-PSS SHA256, ms timestamp, sign full path from root without query params, header is KALSHI-ACCESS-KEY (not KEY-ID)
- **Growth lesson:** Being resourceful means more than just finding data — it means verifying the RIGHT data. Confidence without verification is dangerous.
