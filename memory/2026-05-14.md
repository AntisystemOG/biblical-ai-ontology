Thad requested a Claude Code-style coding interface that auto-spawns a sub-agent with persistent memory.

- `tools/coding-interface/server.py` — Python HTTP server + OpenClaw bridge
- `tools/coding-interface/coder-bridge.py` — CLI tool for spawning agents

### Features:
- Dark theme matching Claude Code aesthetic
- Automatic agent spawning on first message
- Persistent memory via `agents/coder-memory.md`
- Real-time status indicators
- Plan tracking panel
- Keyboard shortcuts (Ctrl+K clear, Ctrl+/ help, Ctrl+N new session)
- File path highlighting
- Message history with timestamps

### How to Run:
```bash
cd tools/coding-interface
python server.py
# Then open http://localhost:18790 in browser
```

### Agent Workflow:
1. User sends first message → spawns Coder sub-agent
2. Agent reads `coder-memory.md` for context
3. Agent executes task
4. Agent updates memory file with changes
5. Session remains active for follow-up messages
