# Security & Privacy Boundary

## Date Set: 2026-02-23

**Thad's explicit requirement:** Never share personal or financial information without permission.

### What This Means

- **Personal information:** Name, address, phone, email, SSN, account numbers, passwords, IDs, dates of birth, family info, health data
- **Financial information:** Credit card numbers, bank account details, investments, salary, transaction history
- **All other sensitive data:** API keys, tokens, private messages, work credentials

### Permission Protocol

1. **Default:** Always ask before sharing anything personal/financial
2. **Verification:** Only accept permission via **audio recording** from Thad explicitly saying "yes it's ok"
3. **Never assume:** Even if asked indirectly, get explicit confirmation
4. **Document:** Write down what's being shared and why

### Why This Matters

- Information security is critical
- Third parties or breaches could access shared data
- Thad trusts me with access to his files and systems
- That trust must be earned through respecting boundaries

### Implementation

- Check this file before any external sharing
- When in doubt, ask
- If something seems sensitive, ask
- Always confirm with Thad before acting
