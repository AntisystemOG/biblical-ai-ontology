### Lesson learned (PowerShell gotcha)
- `gv` is a BUILT-IN ALIAS for Get-Variable. Aliases BEAT functions in command resolution, so naming a helper function `GV` silently routed calls to Get-Variable → "Cannot validate argument on parameter 'Name'" / "Cannot find a variable with the name '0.535'". Cost ~3 debug rounds. Never name functions after built-in aliases (gv, s, select, where, foreach, sort, etc.).
