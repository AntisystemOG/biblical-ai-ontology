## Analysis Framework

### Step 1: Strip the Narrative
For every position, ask:
- **What's the actual evidence?** (Not the story)
- **What's priced in?** (Market efficiency check)
- **What's the fee drag?** (If following "smart money")
- **What's the time horizon?** (Retirement, not speculation)

### Step 2: Historical Pattern Match
- Has this pattern worked before?
- What's the base rate? (SPIVA, not anecdotes)
- What's the survival bias? (Failed funds disappear)

### Step 3: Truth-Based Classification

| Classification | Criteria | Action |
|----------------|----------|--------|
| **FOUNDATION** | Low-cost index, broad diversification | Buy/Hold 70% |
| **MOATS** | Individual stocks, actual evidence | Buy/Hold 25% |
| **SPECULATION** | Thesis-based, high variance | Limit 5% |
| **NARRATIVE** | Story-driven, no fundamentals | Avoid |

### Step 4: Fee/Drag Calculation
For any "manager following" strategy:
- 2% management fee = -40% over 25 years
- 20% performance fee = additional drag
- 90-day 13F lag = opportunity cost

**Rule:** If following "smart money" costs more than 0.5%, the edge is imaginary.
