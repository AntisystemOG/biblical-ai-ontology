## Anticipated Objections — Intralox AI ROI Brief

### "Is this secure? We're using AI on production data."
The tool runs entirely on local Windows machines. No PLC data ever leaves the plant network. The AI subscription is purely for development assistance — the generated code runs locally.

### "What if you leave? Who maintains it?"
The code is standard Python with open-source libraries. Any developer can pick it up. The AI-assisted approach means the tool was built with full documentation in the code and a project memory file — not a black-box vendor solution.

### "Our vendors already provide tools. Why do we need this?"
Vendor tools are expensive, generic, and require licensing that doesn't always follow specific needs. This tool was built for our exact PLC model, machine layout, and tag naming convention. That's the advantage of custom-built — and the AI made that path affordable.

### "$20/month seems too cheap — is this serious?"
That is the point. The AI doesn't replace expertise; it amplifies it. I know these PLCs and these machines. The AI helps write, debug, and structure the code faster — like having a senior developer pair-programming at a fraction of the cost.

### "Do we need permission to keep using this?"
Right now this is a personal subscription being used for work benefit. Formalizing a small departmental budget would let us scale this approach to other pain points — predictive maintenance dashboards, parts tracking, quality data collection.
