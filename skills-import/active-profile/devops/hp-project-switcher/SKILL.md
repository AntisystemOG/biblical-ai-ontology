# hp — Hermes Project Switcher

A lightweight bash function for navigating between coding projects via friendly names instead of full paths.

## Installation

- Script: `/home/thadd/.hermes/bin/hp`
- Registry: `/home/thadd/.hermes/projects.json`
- Sourced from `.bashrc` automatically

## Usage

| Command | Description |
|---------|-------------|
| `hp` | Show interactive numbered menu |
| `hp webui` | `cd` to project by name (partial match works) |
| `hp 2` | `cd` to project by number from menu |
| `hp add myapp ~/code/myapp "My cool app"` | Add a new project |
| `hp rm myapp` | Remove a project |
| `hp ls` | List all projects |
| `hp help` | Show help |

## Features

- **No dependencies** — uses Python 3 (already installed) instead of `jq`
- **Partial name matching** — `hp web` matches `webui`
- **Git awareness** — shows current branch and uncommitted changes on switch
- **Tab completion** — bash completion for project names and commands

## Adding Projects

```bash
hp add trading-bot ~/code/trading-bot "Algorithmic trading bot"
```

Paths with `~` are expanded automatically. Non-existent directories prompt to create.

## Removing Projects

```bash
hp rm trading-bot
```

## Pitfalls

- **Always check the project registry FIRST** before searching the filesystem for project folders. The `hp` registry is the single source of truth for workspace locations. A folder may exist in an unexpected location (e.g., `CODE Projects` under `.hermes/profiles/devteam/` rather than in Documents).
- **Case sensitivity matters** — `Code Projects`, `CODE Projects`, and `code projects` are distinct. The project switcher registry preserves the exact name; search tools do not.
- The `hp` function only works in interactive bash shells (not in scripts) because it uses `cd`
- If `projects.json` is corrupted, back it up and recreate with `hp add`
- Windows paths under `/mnt/c/` work fine — they're stored as-is

## Recreating from scratch

If the script is lost, the full source is at `/home/thadd/.hermes/bin/hp` and can be regenerated by writing the bash function + Python JSON helpers.
